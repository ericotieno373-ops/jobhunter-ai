# JobHunter AI

AI-powered job search platform for Kenya.

## Features

- FastAPI REST API
- PostgreSQL
- SQLAlchemy
- Corporate Staffing scraper
- AI job matching (coming soon)
- CV tailoring (coming soon)
- Cover letter generation (coming soon)

## Run

```bash
uvicorn main:app --reload
```
